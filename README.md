# actuallyakshat/homebrew-tap

Homebrew packages by [@actuallyakshat](https://github.com/actuallyakshat).

```bash
brew install actuallyakshat/tap/tars
brew install --cask actuallyakshat/tap/watchsync
```

| Package | What it is |
|---|---|
| [tars](https://github.com/actuallyakshat/tars) | A task list you and your coding agent share |
| [watchsync](https://github.com/actuallyakshat/watchsync) | Watch local movies in sync with friends on separate Macs |

Casks here are published automatically by each project's release workflow.
